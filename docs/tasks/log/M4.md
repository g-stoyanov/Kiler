The done tasks of [M4.md](../M4.md) with all their notes: the decisions made in the task, the measurements, the review passes and their fixes. A task moves here whole when it is ticked. Read this file only when a note points here, such as "the M4.1 note", or when the history of a decision is needed. Search it by the task number.
